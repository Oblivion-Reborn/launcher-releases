# Oblivion Reborn launcher

Download [Oblivion-Reborn-Setup-2.5.5.exe](Oblivion-Reborn-Setup-2.5.5.exe) and run it.
After the first install the launcher updates itself.

UE4SS-3.0.1a.zip is UE4SS, MIT licence (LICENSE-UE4SS.txt inside). The launcher installs it when a player has none.

The launcher carries RebornNative.dll, an OBSE64 plugin under the GNU GPL v3 with a modding exception. Its full source is in RebornNative-source; build it with xmake against CommonLibOB64 (see .gitmodules).

Version 2.5.5.
